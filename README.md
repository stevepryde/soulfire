# soulfire
Interactive Fiction and AI experience app.

A single-user, local, BYOK desktop/mobile app built in Rust + Dioxus. See [`specs/`](specs/) for the
design (source of truth) and [`AGENTS.md`](AGENTS.md) for how it's built.
